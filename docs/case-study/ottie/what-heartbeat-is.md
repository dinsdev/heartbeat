Heartbeat is a small neural network that labels heartbeats from one ECG lead, trained on the public MIT-BIH Arrhythmia Database. It is shown beside a logistic-regression baseline and tested on patients it never saw. Dinesh did all of it alone: the question, the plan written before the test, the data pipeline, both models, the evaluation, the browser demo and the write-up. It is a research demo, not medical advice, and it should not be used for a health decision.
